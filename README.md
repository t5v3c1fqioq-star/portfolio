# Sadeq Al-Kaabi · Portfolio

Static portfolio site. Hosted on Netlify, edited from `/admin` (Sveltia CMS, signs in with GitHub).

- `index.html` — the whole site (design, intro, players)
- `data/portfolio.json` — all content: profile, sections, videos, films, logos, experience
- `media/` — previews, thumbnails, the main film (`media/film`), TV spots (`media/tvc`), long films (`media/long`)
- `media/uploads/` — files added from the editor
- `admin/` — the editor
